T16 : repérage des registres V4E (méthode, utile aux sessions suivantes)

Les URL « show/<fiche>/image/<fiche−122877>/<page> » fonctionnent pour les fiches 359729 à ~374214 (V4E 1860-1870 puis 1871-début 1875 dans le 10e) ; une fiche = un paquet de 30 images, « page » = rang dans le paquet (0-29) ; l'en-tête HTTP « content-disposition » donne la cote (v4e-03383) et le n° d'image du registre. T25 : méthode d'accès au moteur de recherche des Archives de Paris (utile aux sessions suivantes)

Les formulaires « Consulter les actes d'état civil / tables / successions » sont des moteurs Arkothèque interrogeables en GET, sans compte, avec curl ou urllib :

  1. Page du formulaire → attribut data-moteur="arko_default_…" ; https://archives.paris.fr/_recherche-api/moteur?refUnique=<ref> donne l'id numérique (état civil actes = 32 ; tables décennales = 3 ; tables de décès DQ8 = 1 ; fichier successions DQ7 = 12 ; reconstitué fichiers = 4, actes = 29) et les filtres.
  2. Recherche : https://archives.paris.fr/_recherche-api/search/<id>?<ref>--from=0&<ref>--resultSize=100&<ref>--filtreGroupes[mode]=simple&<ref>--filtreGroupes[op]=AND&<ref>--filtreGroupes[groupes][0][<refFiltre>][op]=AND&<ref>--filtreGroupes[groupes][0][<refFiltre>][q][]=<valeur> (préfixe = refUnique du moteur + « -- »). Filtres à valeur discrète (type de document, arrondissement « 10 », « 09 ») fonctionnent ; les filtres « année » et « date » n'ont rien renvoyé (format non trouvé) : on pagine donc tout l'arrondissement et l'on filtre soi-même. La réponse JSON contient html (tableau : début/fin de registre avec dates et numéros d'actes, cote, nombre d'images, attribut data-visionneuse avec idArkoFile) et results[].id (= identifiant de fiche).
  3. Image : https://archives.paris.fr/_recherche-images/show/<id fiche>/image/<idArkoFile>/<pos> (pos 0-indexé ; id fiche − idArkoFile = 122879 pour V4E 1883-1895 ; 69 pour le fichier DQ7 ; 69 ou 70 pour DQ8 selon la fiche : lire l'écart dans la liste des résultats). Les registres sont découpés en fiches d'une quinzaine de jours ; la dernière fiche de chaque registre contient les « tables alphabétiques » (une page = une lettre ou presque), qui donnent le numéro d'acte.
  4. Répertoires d'inhumation de Montmartre : fiches 43910 (1900-1904), 43920-43926 (1905-1911), 43927-43935 (1912-1920), 43936+ (1921-1930), décalage 110 ; pages simples, ordre alphabétique.
